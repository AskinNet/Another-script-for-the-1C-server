Скрипты для управления 1с сервером

## Что это

`svc1c.os` — скрипт на OneScript для ночного обслуживания баз на сервере 1С:Предприятие 8.3. Он блокирует базы и выгоняет пользователей, обновляет конфигурацию из хранилища, применяет обновление базы данных, при необходимости перезапускает службы сервера 1С и снимает блокировку. Всё это по одному конфигу и одной команде, поэтому удобно ставить в планировщик заданий вместо ручной работы в консоли кластера.

## Как поставить

Нужны установленный сервер 1С, OneScript 2.x в `C:\Program Files\OneScript` и служба RAS (команда для её создания есть в `AGENTS.md`). Склонируйте репозиторий и в его папке выполните `powershell -ExecutionPolicy Bypass -File install.ps1`: он скачает библиотеки и проверит скрипт. Затем скопируйте `demo-server.yml` под свой сервер, впишите базы и пароли и запускайте `batch.bat` вручную или из планировщика.

## Как поставить с помощью агента

Откройте папку репозитория в Claude Code, Codex или другом агенте и попросите: «установи и настрой скрипт по AGENTS.md для сервера такого-то, тестовая база такая-то». В `AGENTS.md` описаны установка, служба RAS, все параметры конфига и порядок проверки на тестовой базе. Логины и пароли агенту дайте сами: подбирать их он не будет, а в git они не попадут.
